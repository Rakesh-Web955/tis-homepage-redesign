## Project Overview

This project redesigns the Tulas International School homepage while retaining the core TIS branding, content direction, and school information from the provided reference material.

The experience is designed to feel modern, engaging, responsive, and easy to navigate across desktop, tablet, and mobile devices.

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Custom CSS for advanced visual effects and responsive styling
- Framer Motion for animations and scroll-triggered interactions
- Lucide React for interface icons
- React Icons for social media icons

## Key Features

1. **Custom Cursor**
   - Desktop-only interactive cursor.
   - Expands when hovering over interactive elements.

2. **Scroll-Triggered Reveals**
   - Sections and cards animate into view using Framer Motion.
   - Animations are configured to run efficiently as elements enter the viewport.

3. **Theme Switcher**
   - Supports light and dark themes.
   - Theme preference is stored using localStorage.

4. **Scroll Progress Bar**
   - Displays reading progress at the top of the page.

5. **Responsive Navigation**
   - Desktop navigation transforms into a mobile menu on smaller screens.

6. **Responsive Layout**
   - Designed for desktop, tablet, and mobile screen sizes.

7. **Animated Sections**
   - Hero, academics, sports, recognition, testimonials, statistics, and admission sections include interactive visual elements.
